# Breathe Better — 2 minute 40 second demo recording plan

Record only after the live provider keys are configured and the public app is verified. This document is a script, not a recorded video. Do not show provider dashboards, secrets, personal browser tabs or API keys in the recording.

## 0:00–0:15 — Problem and purpose

Screen: Overview, Chennai.

“Breathe Better helps people understand the air around them, compare places and plan outdoor time. It combines station measurements, clearly labelled air-quality models and weather context.”

## 0:15–0:40 — Sources and current data

Screen: Current model dashboard, pollutants, then station observations.

“The overview labels CAMS model estimates separately from OpenAQ observations. Each station shows its provider, units and timestamps. This PM-only US AQI is derived from observed particle data using the EPA NowCast. It does not include gases, and it is not an official complete station AQI.”

Show unavailable readings honestly if a station lacks coverage. Never describe the model card as an observed station reading.

## 0:40–1:05 — Map and places

Screen: Explore map. Select a city marker, then search for another location.

“Users can explore different locations and inspect colour-coded model AQI. The global model is coarse, so this map does not claim street-level accuracy. Location search and optional geolocation help users find their area.”

## 1:05–1:30 — Measured history

Screen: History, choose a reporting monitoring station. Select seven or thirty days and compare two dates.

“Station history shows measured PM2.5 and PM10. Derived daily indices require complete daily periods and adequate data coverage. Missing dates remain gaps. Percentage changes and transparent spike flags help explain changes over time. Model history appears separately below.”

If no measured history is available, state the limitation and choose a station with real coverage; never substitute model values in the station section.

## 1:30–1:50 — Comparison

Screen: Compare. Choose Chennai, Bengaluru and Delhi.

“The comparison uses a consistent model and US AQI scale. It shows pollutant differences, recent trends and the relatively cleaner locations among the cities loaded. A lower value is not a guarantee of safe air.”

## 1:50–2:15 — Forecast and AccuWeather

Screen: Forecast, then weather panel.

“The next 48 hours are clearly marked as forecasts. The planner ranks the hours with the lowest predicted AQI. AccuWeather adds temperature, RealFeel, wind, humidity, UV and a daily weather forecast. Weather information is separate from air pollution data.”

## 2:15–2:40 — Practical use and close

Screen: Health guide, in-app AQI alert, report export and methodology.

“Users can understand AQI categories, review general precautions, enable an in-app threshold alert and download a report. Alerts work while the page is open. Sources, calculation methods and limitations are visible in the app.”

“Breathe Better turns environmental data into practical context for everyday decisions.”

## Recording checklist

- Open the public app without signing in to confirm judges can access it.
- Verify both APIs return actual data and station coverage is adequate.
- Use a clean browser window with no keys or personal information visible.
- Record at readable resolution; 1080p landscape is preferred.
- Keep the final recording between two and three minutes.
- Include the live URL and public GitHub repository in the submission.
- Watch the exported video and check its audio and permissions before submitting.
